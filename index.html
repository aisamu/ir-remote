ELKSMART USB-C IR blaster

Plug in the blaster, then connect to enable the controls.

Point the blaster at the cooler. Each tap sends one command. IR is one-way: check the cooler itself for its current setting.

Connection help & limitations

Use a WebUSB-capable browser, such as Chrome on Android or a desktop Chromium browser. Android requires USB host support. If Samsung Browser does not show a USB chooser, open the page in the full Chrome app. Safari and iOS are not supported.

Open this page over HTTPS, or use localhost on the computer serving it. A file opened directly from storage is not the supported setup. No app or account is needed.

Connecting does not send IR. An acknowledgement confirms the blaster accepted a command, not that the cooler received it. If a send fails, check the cooler before retrying: repeating a toggle can undo the action.
